# StudySprint — Student Academic Survival Hub

A beginner-friendly web app built with HTML, CSS, and JavaScript for the CPP123 Emerging Technology final project.

## Features
1. Assignment and deadline manager (add, edit, delete, complete, search, and filter tasks).
2. Dashboard summary for total, completed, due-soon, and overdue tasks.
3. Quick quiz reviewer with automatic scoring, answer explanations, and best-score tracking.
4. Focus timer with 25-minute study, 5-minute break, and 15-minute focus presets.
5. Privacy Policy page.
6. Responsive layout for desktop and mobile browsers.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Add sample tasks and test all features.

No build step or package installation is required.

## Publish online
You can publish the files with GitHub Pages or Netlify. Upload `index.html` (or the entire extracted folder) and verify the public URL in another browser or device.

## Important notes
- Tasks and quiz best score are stored in browser local storage. They do not sync across devices.
- This version does not use an account system or remote database.
- The Privacy Policy is written for this current version. If you add analytics, accounts, a database, or third-party services, update the policy to match the actual behavior.
- Use sample/fictitious information for coursework and do not store sensitive personal data.
- Review and understand the code, test it, and customize the project before submitting. Document the AI prompts you actually use and the changes you make.
